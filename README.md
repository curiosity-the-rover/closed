## Калькулятор Васту

Веб-калькулятор Васту-шастры для **квартир, частных домов с участком, офисов и магазинов**.
Вы вводите план помещения, а он рассчитывает, насколько планировка благоприятна, отмечает каждую комнату и деталь на плане и формирует отчёт в **PDF** или **PowerPoint**.

## Как открыть

- **Локально.** Скачайте репозиторий и откройте `index.html` двойным щелчком. Сервер и интернет не нужны: все библиотеки лежат в `vendor/`.
- **Онлайн.** https://curiosity-the-rover.github.io/closed/ — сайт публикуется из ветки `gh-pages`, которую workflow обновляет при каждом изменении `main`.

При первом запуске загружается пример квартиры. Нажмите **«▶ Рассчитать»**, а затем **«Сформировать отчёт» → PDF / PowerPoint**.
В списке сверху есть ещё три готовых примера: дом на участке (с вырезом и Аяди), офис (верх плана смотрит на восток) и магазин со входом с юга.

## Что умеет

| Раздел | Что делает |
|---|---|
| Исходные данные | Тип объекта, азимут верха плана (компас), комнаты (тип, x, y, ширина, глубина), детали (вход, плита, кровать, сейф, стол, зеркала, вода, щиток, баки и т. д.) и направление «лицом / изголовьем» |
| Участок (для дома) | Уклон, водоёмы, высокие здания, вити-шула (дорога, упирающаяся в участок), дороги по сторонам, свободное место на С/В, Аяди-шадварга |
| 2D-план | Перетаскивание комнат и деталей мышью, изменение размера за угол, сетка 16 зон, мандала 9×9 (32 пады и внутренние божества), Брахмастхан, подсветка вырезов, компас |
| Анимация | «Радар» обходит план по часовой стрелке и окрашивает зоны. «Прогулка» проводит точку от входа по всем комнатам и показывает оценку каждой. Дефекты пульсируют |
| 3D-модель | Стены, полы в цветах оценки, поднимающиеся «ауры» комнат, кольцо 16 зон, стрелка севера, детали; вращение и масштаб, автоповорот |
| Результат | Балл 0–100, вердикт, разбор каждого пункта с зоной и азимутом, фильтр «дефекты / сильные стороны», рекомендации по исправлению |
| Отчёт | PDF (A4, кириллица) и PPTX (16:9): титул, сводка, план, 3D-снимок, таблицы, дефекты с рекомендациями, Аяди, стороны света, источники |
| Проект | Автосохранение в браузере, экспорт и импорт JSON |

## Методика

- **Центр** — центр габаритного прямоугольника плана. **Брахмастхан** — центральная 1/9 часть (3×3 клетки мандалы 9×9).
- **Направление комнаты или детали** определяется по азимуту её центра от центра плана с учётом того, куда смотрит верх плана:
  8 сторон по 45° (основные правила), 16 зон по 22,5° (уточнения, например допустимые зоны для санузла: ВЮВ, ЮЮЗ, ЗСЗ).
- **Главный вход** оценивается по 32 падам внешнего кольца мандалы (сектора по 11,25°: N1…N8, E1…E8, S1…S8, W1…W8).
- **Форма**: пропорции сторон и вырезы. Клетка 3×3, заполненная меньше чем на 60 %, считается вырезом; вырезы на СВ и ЮЗ весят больше.
- **Оценки** от −2 до +2 с весами (кухня, спальня хозяев, вход, центр весят больше). Итог — взвешенная сумма, приведённая к 100.
- **Аяди** считается по периметру в колах, хастах или метрах: Ая, Вьяя, Йони, Накшатра, Вара, Титхи (один из распространённых вариантов формул).

Все правила собраны в одном файле `js/data.js`, их легко поправить под свою школу.

## Источники

- Брихат-самхита (Варахамихира, VI в.), гл. 53 «Вастувидья»
- Майямата, Манасара — мандалы, пропорции, Аяди
- Самарангана Сутрадхара (Бходжа, XI в.) — 45 божеств мандалы, дефекты
- Вишвакарма Пракаш, Апараджитапрччха, Раджаваллабха — входы, комнаты, вити-шула
- Современная практика 16 зон и 32 входов

> Трактаты расходятся в деталях (особенно в Аяди и значениях пад входа). Калькулятор реализует обобщённые правила и не заменяет строительную экспертизу.

## Структура

```
index.html         интерфейс
css/style.css      стили (светлая и тёмная тема, адаптивная вёрстка)
js/data.js         справочники и правила Васту
js/examples.js     готовые примеры
js/engine.js       расчётный движок (без DOM)
js/plan2d.js       2D-план на SVG, редактирование, анимации
js/view3d.js       3D-модель (three.js)
js/report.js       отчёты PDF (pdfmake) и PPTX (PptxGenJS)
js/app.js          связка интерфейса
vendor/            three.js r128, pdfmake 0.2.10, PptxGenJS 3.12.0 (MIT)
```
